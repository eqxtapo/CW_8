# Трекер привычек

## Описание

Проект вдохновлен книгой Джеймса Клира «Атомные привычки», 
которая посвящена приобретению новых полезных привычек и 
искоренению старых плохих привычек.

## Возможности

- Полный CRUD для задач: Создавайте, просматривайте, обновляйте и удаляйте задачи.

- Аутентификация по JWT: Регистрация и вход для защиты ваших задач.

-  Интерактивная документация: Автоматически сгенерированные документация Swagger UI.

- Реляционная база данных: Использует PostgreSQL для надежного хранения данных.


## Технологии

Framework: FastAPI

Database: PostgreSQL

Authentication: JWT (JSON Web Tokens)

Environment Variables: python-dotenv


##  Установка и запуск

### Предварительные требования

- Python 3.10+
- PostgreSQL (для production)
- pip (менеджер пакетов Python)

### 1. Клонирование репозитория

```
https://github.com/eqxtapo/DW
```
### 2. Установка зависимостей
```
# Создание виртуального окружения
python -m venv venv

# Активация на Windows
venv\Scripts\activate
# Активация на macOS/Linux
source venv/bin/activate

# Установка зависимостей
pip install -r requirements.txt
```
### 3. Настройка базы данных
Создайте базу данных в PostgreSQL.

Создайте файл .env в корневой директории проекта, скопировав шаблон из .env.example:

Заполните файл .env своими реальными данными для подключения к БД и секретным ключом.



### 5. Запуск приложения
```
# Development сервер
python manage.py runserver

```

## API Документация
После запуска сервера автоматически станет доступна интерактивная документация:
